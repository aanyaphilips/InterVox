# InterVox

InterVox is a browser-based AI mock interview prototype for guided first-round practice. It asks structured questions aloud, captures spoken answers when the browser supports speech recognition, offers an optional camera preview, and creates a transparent practice report.

## What is included

- Five-question interview flow
- Mandatory resume upload with file integrity and structure screening before the session starts
- Mandatory camera permission for the full interview session
- Text-to-speech question playback using the browser
- Microphone permission and recording support
- Speech-to-text when `SpeechRecognition` or `webkitSpeechRecognition` is available
- Typed-answer fallback for browsers without speech recognition
- Optional live camera preview using `getUserMedia`
- Assistive score breakdown for clarity, ownership, adaptability, collaboration, and motivation
- Unrelated or missing answers are explicitly marked as not scored
- Confidence signal based on recorded delivery when voice capture is available
- Qualified / not-qualified-yet practice outcome
- Downloadable and shareable report
- Responsive layout for desktop and mobile screens

> InterVox is an educational and practice prototype. Its score is not a final hiring decision and should not be used as the sole basis for evaluating a candidate.

## Run locally

This repository uses pnpm workspaces.

```bash
pnpm install
pnpm --filter @workspace/intervox run dev
```

Open the URL shown by Vite. Camera and microphone permissions work on `localhost` and on secure HTTPS deployments.

## Browser notes

- Spoken questions use the browser's built-in `SpeechSynthesis` API.
- Spoken answer transcription depends on browser support for `SpeechRecognition` / `webkitSpeechRecognition`.
- If speech recognition is unavailable or permission is denied, type the answer in the response box instead.
- Camera access is required for this interview prototype and must remain enabled for the session.
- The resume screen checks file format, integrity markers, structure, and obvious placeholder flags. It cannot independently verify a person's identity or employment history.
